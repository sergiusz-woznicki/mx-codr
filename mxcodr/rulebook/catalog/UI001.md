# UI001 — a data grid filters itself, not through inputs over a helper entity

## What it checks
A data grid is filtered with its own filter widgets, not with text boxes and checkboxes over a helper entity. A filter bar above the grid is allowed and is built from those widgets.

## Fix
One filter in the column (`textfilter`, `numberfilter`, `datefilter`, `dropdownfilter`, for an association `(Association: ..., datasource: database ..., CaptionAttribute: ...)`). A filter bar above the grid: the same widgets in the grid's `controlbar { }`, each linked to its column (`attrchoice: linked, attributes: [Mod.Entity.Attr]`, or `association: Mod.Assoc, datasource: database Mod.Other, captionattribute: Attr`); card GRID03 has the example.
