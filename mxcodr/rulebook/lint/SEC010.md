# SEC010 — a page lists an entity the roles that open it cannot read

## What it checks
mxcli lint rule SEC010 (PageEntityNotReadable, mxcli 0.27): a list view, data grid, reference selector or combo box lists an entity that none of the roles opening the page may read, so at Production it renders empty with check, build and runtime log all clean. The harness checks this nowhere else. mxcli rates a widget its roles read only through an XPath-constrained rule as info: that is the row scoping ISO01 asks for, so those findings drop out. Decided 2026-10-16 when mxcli 0.27 brought the rule.

## Fix
In the finding: mxcli's message and its suggestion.
