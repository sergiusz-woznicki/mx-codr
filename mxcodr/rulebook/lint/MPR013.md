# MPR013 — Checks for snippet calls with Class, Style, DynamicClasses or design properties, which never reach the page (a snippet call renders no element)

## What it checks
mxcli lint rule MPR013 (SnippetCallAppearance, mxcli 0.28): Checks for snippet calls with Class, Style, DynamicClasses or design properties, which never reach the page (a snippet call renders no element). The styling is silently dropped, so a page looks different from what its author wrote; no other check of the harness sees it, and mx check accepts it. Decided 2026-10-25 when mxcli 0.28 brought the rule.
